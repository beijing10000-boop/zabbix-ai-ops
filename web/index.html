系统配置

模型、MCP、飞书及告警设置。敏感字段始终只显示掩码。

飞书企业应用告警：开启飞书通知；使用已保存的飞书 App ID/Secret，并填写企业应用告警群 Chat ID（oc_ 开头，机器人必须已加入该群且具备发消息权限）。不需要单独的群 Webhook URL 和签名密钥。平台仅使用飞书企业自建应用，不支持群自定义机器人 Webhook。首次建议先在测试群验证。
当前默认 HTTP。可修改 Web 访问协议为 https 并填写外部域名/IP；HTTPS 证书与反向代理需要在服务器配置。修改协议后需同时更新飞书开放平台的重定向 URL，并重新登录。HTTP 登录会明文传输会话，请仅在隔离测试环境使用。
