运行安全

AI 问答只允许只读 MCP 工具。实际写入操作仍需独立审批和执行器。写入必须使用独立 MCP 令牌，并经指定飞书管理员二次确认；默认关闭。

系统配置

模型、MCP、飞书及告警设置。敏感字段始终只显示掩码。

飞书企业应用告警：选择 app，开启飞书通知；使用已保存的飞书 App ID/Secret，并填写企业应用告警群 Chat ID（oc_ 开头，机器人必须已加入该群且具备发消息权限）。不需要单独的群 Webhook URL 和签名密钥。平台仅使用飞书企业自建应用，不支持群自定义机器人 Webhook。首次建议先在测试群验证。
当前默认 HTTP。可修改 Web 访问协议为 https 并填写外部域名/IP；HTTPS 证书与反向代理需要在服务器配置。修改协议后需同时更新飞书开放平台的重定向 URL，并重新登录。HTTP 登录会明文传输会话，请仅在隔离测试环境使用。

MCP 权限分离与写入控制

只读 MCP 供 AI 查询；写入 MCP 仅供已审批的受限执行器使用。两套令牌应来自权限不同的 Zabbix 账户。

只读 MCP：在 MCP Server 中配置使用 Zabbix 只读 API 用户的连接与令牌，Web 的 MCP 测试与 AI 查询使用它。
写入 MCP：使用单独的 MCP 服务实例和 Zabbix 最小写入权限账号。写入令牌仅允许确认告警事件，不要给普通问答开放写入工具。
如何获取：登录 Zabbix → 用户 → API 令牌创建对应账号的令牌；MCP URL/认证 Token 按你部署的 MCP Server 配置获取，Zabbix API 令牌不一定等于 MCP Bearer Token。
