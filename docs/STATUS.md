# 开发状态（v0.1 开发预览）

## 已提交的模块（尚未完成生产环境端到端验证）

- FastAPI：健康检查、配置保存、基本审计及 Zabbix Webhook。
- Web 页面：编辑 AI、MCP、飞书及告警参数。
- SQLite 持久化 + Fernet 密钥加密 + 管理员 Token。
- Redis/RQ 告警 Worker，AI Responses 分析、MCP 只读证据、飞书自定义告警卡片。
- **飞书企业应用 WebSocket 问答接收**，群白名单、去重与 `ai-questions` Worker。
- **飞书“分析中 → 分析完成”同卡片更新**，失败时兜底发送普通消息。
- **AI 动态 MCP 只读工具调用**：只允许代码中明确列出的查询工具。
- Docker Compose、CI 基础测试。
- 中英文文档规划、配置与故障排查说明。

## 未完成 / 不能承诺

- 生产 Zabbix MCP 参数兼容性与不同飞书权限的完整集成测试。
- Web 上的模型和 MCP 连通性测试、任务历史可视化、多用户 RBAC。
- 飞书回复某条告警 @AI 自动识别事件。
- 管理员二次审批后通过 MCP 修改 Zabbix（**不可用，写入默认禁止**）。
- 飞书 Webhook 签名发送、发布产物、自动升级与回滚。
- 大量监控主机性能、异常重试、消息幂等的生产级压力测试。
