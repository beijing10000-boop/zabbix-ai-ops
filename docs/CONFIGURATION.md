# 配置规划

Web 后台将管理：Zabbix Webhook 入口、MCP 服务及只读工具权限、Azure/OpenAI 模型、飞书机器人与群白名单、告警级别颜色、AI 提示词和重试策略。

计划支持告警等级 0–5 的六种颜色；告警卡片包含主机名、IP、主机组、事件、原因（100字）、建议（150字）、AI 分析（500字）。人工介入判断在标题中，不在 AI 分析中重复。默认不 @ 人员、不发加急。

系统密钥：通过首次初始化引导保存，后续只显示掩码。不得提供从 Web API 读取明文密钥的接口。MCP 写入功能独立凭证、默认关闭且必须审批。

`.env.example` 是开发配置示例，**不代表 Web 后台已经完成**。
